# 台灣慣用詞（zh-TW）

> 適用於使用者介面文字、權限名稱、文件、commit 訊息。產品使用者在台灣時，中國用語會讓產品看起來不在地。

## 常見替換

| 避免 | 改用 |
|------|------|
| 群發 | 大量寄送、依情境另取名（例如「通知信」） |
| 信息 | 訊息、資訊 |
| 用戶 | 使用者 |
| 默認 | 預設 |
| 視頻 | 影片 |
| 數據 | 資料（統計情境可用「數據」） |
| 優化（UI 文案） | 改善、調整（commit 動詞可以保留「優化」） |
| 質量 | 品質 |
| 項目（指專案） | 專案 |
| 文檔 | 文件 |
| 運行 | 執行 |
| 支持（功能） | 支援 |
| 程序（指程式） | 程式 |
| 登錄（指登入） | 登入 |
| 批次（指一次執行的排程工作） | 任務 |

## 怎麼做

- 新功能的畫面文字、權限名稱、角色描述，都先依台灣語感檢查一遍。
- 改名時給整組搭配（功能名稱、模板名稱、單筆項目名稱），並附優缺點表讓使用者選。
- 程式識別字（類別、路由、資料表）可以刻意不改，只改使用者看得到的文字，以避免大規模重構。
