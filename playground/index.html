攔截規則

「內建」來自 scripts/lib/guard-rules.tsv，「團隊」是你新增或匯入的規則，比對時排在內建規則後面。佔位符：{S} 空白、{NS} 非空白非引號、{E} 字詞結尾。

團隊規則檔 .agreements/guard-rules.tsv

貼上團隊現有的規則檔再按「匯入」，會取代標成「團隊」的規則。改好後「匯出」或「下載」，存成 .agreements/guard-rules.tsv commit，Claude Code 就會照這些規則攔截。

    一行一筆。指令會先依 && || ; 切成子指令，逐段比對；命中攔截式、而且沒命中放行例外，就拒絕。
